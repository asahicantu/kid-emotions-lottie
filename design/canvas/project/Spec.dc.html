Pipeline

  1. Pose: each emotion sets ~50 face channels per frame.
  2. Scene: channels become named groups and bezier paths.
  3. Output: the same scene renders as SVG (canvas, preview) or is baked into Lottie keyframes.

Shaded rows are the face rig, where most keyframes live. Names match the groups in the exported JSON, so they can be targeted with dynamic properties.

Build rules

  • Every mouth pose is the same 2-vertex closed path; lids are always 5 vertices. Fixed counts are what let Lottie morph them.
  • Lids are animated paths, not masks, so they stay cheap on iOS and Android.
  • Every oscillation completes whole cycles per segment, so each loop is seamless.
  • No expressions, effects, images or text layers: plays in lottie-web, lottie-ios and lottie-android.
  • Switching segments inside a Lottie player is a cut; the 9-frame blend exists only in the live rig.
